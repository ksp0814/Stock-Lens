# Stock Lens

종목 이름이나 코드를 입력하면 토스증권 Open API의 일봉 데이터를 바탕으로 최근 가격 흐름과 기술적 지표를 요약하는 작은 웹 앱입니다.

## 실행

Node.js 20.6 이상이 필요합니다.

```bash
npm.cmd start
```

`.env.local`의 `PORT`가 `3100`이면 브라우저에서 `http://localhost:3100`을 엽니다.

토스증권 API 자격증명 설정:

프로젝트 루트의 `.env.local` 파일에 입력합니다.

```dotenv
TOSSINVEST_CLIENT_ID=발급받은_client_id
TOSSINVEST_CLIENT_SECRET=발급받은_client_secret
PORT=3100
```

`.env.local`은 Git에 포함되지 않습니다. 토스증권 WTS의 Open API 설정에서 현재 호출 IP를 허용 목록에 등록하고, 키 값을 코드·브라우저·채팅에 노출하지 마세요.

테스트:

```bash
npm.cmd test
```

배포 서비스의 시작 명령은 `npm.cmd run start:prod` 또는 `node src/server.js`를 사용합니다. 배포 환경에는 `TOSSINVEST_CLIENT_ID`, `TOSSINVEST_CLIENT_SECRET`, `PORT`를 환경변수로 등록하고 `/health`를 헬스체크 경로로 지정하세요. `.env.local`은 배포하지 않습니다.

## 입력 형식

종목 이름을 우선 입력할 수 있으며, 토스증권 종목 코드도 지원합니다.

- 이름: `삼성전자`, `SK하이닉스`, `애플`
- 미국 코드: `AAPL`, `MSFT` 또는 `AAPL.US`, `MSFT.US`
- 한국 코드: `005930` 또는 `005930.KR`

입력창에 두 글자 이상 입력하면 후보 목록이 입력창 바로 아래에 표시됩니다. 후보는 시가총액이 큰 순서로 정렬되며, 시가총액을 확인할 수 없는 후보는 뒤로 배치됩니다. 후보를 클릭해 입력값을 확정할 수 있습니다.

이름 검색은 토스증권의 시장별 활성 종목 목록을 처음 한 번 받아 메모리에 24시간 캐시합니다. 같은 이름의 후보가 여러 개면 임의로 선택하지 않고 후보를 표시합니다.

## 분석 범위

- 최근 종가와 1일 변화
- 약 1개월·3개월 수익률
- 20일·50일 이동평균
- 연환산 변동성
- 조회 구간의 최대 낙폭
- 최근 200거래일 종가 차트와 기술적 관찰
- 일봉·주봉·월봉 선택 차트
- 1·3·5·10·30분봉 조회(1분봉 원천, 5초 간격 갱신)
- OHLC 캔들·거래량 막대·마우스 오버 상세 툴팁
- 국내·미국 시장 캘린더 기반 장 상태 배지

데이터는 토스증권의 `GET /api/v1/candles`를 서버에서 조회합니다. 실시간 1분봉은 REST 폴링 방식이며, 틱 단위 WebSocket 스트리밍은 아직 포함하지 않습니다. 재무제표, 뉴스, 주문, 투자 추천도 포함하지 않습니다. 데이터 지연·누락·API 한도·허용 IP 설정의 영향을 받을 수 있습니다.

실시간 분봉을 선택하면 현재가·오늘 시가 대비 변화·조회 구간 수익률·VWAP·분봉 변동성·구간 낙폭을 계산합니다. 일봉·주봉·월봉을 선택하면 일봉 기준 지표로 돌아갑니다.
